# Обследование ребёнка

Статическая страница для диагностической беседы с ребёнком. Четыре методики:

- **Самооценка** по Т. Дембо — С. Я. Рубинштейн (интерпретация А. Б. Яньшина): шкалы по одной, ребёнок рисует чёрточку, волнистую линию и галочку, строится профиль.
- **Картинки** по типу методики Р. Жиля: ребёнок рисует на сюжетных картинках (ручка, фломастер, маркер, заливка, ластик); всё записывается и воспроизводится.
- **Эмоции: мамы и дочки** — составить пары по эмоциям.
- **Социальные ситуации** — истории в картинках, недостающий кадр перетаскивается в пустую клетку.

Результаты хранятся только в браузере, где проходило обследование (localStorage). На сервер ничего не отправляется.

Запуск: открыть `index.html` или включить GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
